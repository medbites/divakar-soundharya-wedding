The "Cabin audio" button in the top right looks for /assets/bg.mp3.
If the file is missing (as it is now) the button still works: it falls
back to a softly synthesised tambura drone in the Mohanam scale,
generated in the browser with the Web Audio API. No file is required.

To use your own music instead, save it as:  assets/bg.mp3
